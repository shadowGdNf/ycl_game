## 1. 新启程 · 网页战役

以守住王国为目标的塔防游戏。玩家在十八处战场中布置防御塔、指挥英雄，搭配火雨和援军抵御敌军。当前网页版本包含四类基础塔、受关卡限制的 1–4 级升级、杰拉尔德、逐关解锁和通关星级。

### 玩法

- 点击金色建造点选择防御塔，通过不同塔型搭配建立防线；已建塔可以升级或出售，兵营可以调整集结点。
- 指挥英雄阻截敌军，在合适的位置施放火雨和援军，应对密集波次或漏怪。
- 击败全部波次并守住防线即可过关；突破防线的敌人会扣除生命，生命耗尽则失败。
- 支持暂停和 1× / 2× / 3× 速度。战役进度、星级可在远征地图导出和导入，战斗中途不保存。

**电脑操作：**鼠标点击；`1–4` 建塔，`Q` 火雨，`W` 援军，`E` 英雄，`N` 下一波，`空格 / P` 暂停，`Esc` 取消。**手机操作：**点击选择和施放技能，双指或缩放按钮调整视野，放大后拖动地图。

本版本基于所提供 APK 的资源和关卡数据重建浏览器运行层，并非原 APK 的完整等价移植；复杂 Boss 阶段、场景机关、扩展塔、技能树等内容尚未完整还原。

## 2. Jelly Flow · 软糖分流

一款英文界面的轻量解谜游戏。把不同颜色的软糖送进对应杯子，在有限等待区内安排释放顺序。共有 20 个逐步增加难度的关卡，没有倒计时，可以从容思考。

### 玩法

- 点击一个软糖槽，释放槽口最前面连续同色的一组软糖。
- 软糖自动进入第一个尚未装满的同色杯子；杯子装满后，下一个杯子接替。
- 暂时没有匹配杯子的软糖进入 **6 格等待区**；出现同色杯子后会自动收集，等待区溢出则失败。
- 收集全部软糖即可过关。可以使用撤销、重开和提示；不使用提示或撤销通关可获得三星。

**电脑操作：**鼠标点击或数字键 `1–6` 释放，`Z` 撤销。**手机操作：**点击软糖槽或编号按钮。界面中的 `Undo` 为撤销、`Restart` 为重开、`A little hint` 为提示、`Levels` 为选关。

游戏会在当前浏览器保存关卡解锁、星级和未完成对局，支持音效开关与减少动态效果。

## 3. 背包机甲 · Backpack Mecha

把回收的零件拼成机甲，再带着自己的构筑进入战场。游戏结合 **5×5 背包装配、自动攻击和手动走位**：格位、供电、武器与支持件的连接共同决定战斗能力。默认中文，可切换英文。

当前 v0.1 包含四种可逐步解锁的机体、36 件模块、十二种普通敌人、六种 Boss，以及三章十二场远征；也可以选择首章训练或两章试炼。

### 玩法

- 战斗中武器自动索敌，玩家负责移动、躲避红色预警、冲刺和开启超载。
- 战后使用碎片购买模块，在背包中拖动、旋转和安排位置；备件需要装入背包才会生效。
- 最多同时装备三件武器。支持件必须与兼容武器边缘相邻，每把武器最多连接两件支持；还要满足电力上限。
- 通过水与电、油与火、实弹与穿甲、近战震荡、无人机或冰霜回弹等组合形成不同流派。
- 击败章节 Boss 后选择扩容和协议，继续推进；利用新解锁的机体、随机商店、事件与难度重新开局。

**电脑操作：**`WASD / 方向键` 移动，`空格` 冲刺，`E` 超载，`P / Esc` 暂停，装配时 `R` 旋转。**手机操作：**左侧拖动摇杆移动，右侧按钮使用技能；背包支持点击放置和拖动。

支持暂停、切后台自动暂停和本地续局。当前属于可玩试玩版，真机性能、真人试玩和部分数值仍需继续验收与调优，详见[测试报告](backpack-mecha/game/docs/QA.md)。

## 本地启动

以下命令从仓库根目录开始，分别在不同终端中执行。新启程需要 Python 3.9+；另外两款游戏建议使用 Node.js 24+。

### 新启程 · 网页战役

```sh
python3 target/xinqicheng/serve.py --port 8765
```

启动后打开 [http://localhost:8765/](http://localhost:8765/)。

### Jelly Flow · 软糖分流

```sh
cd jelly-flow
npm ci
npm run build
npm run dev
```

启动后打开 [http://localhost:4173/](http://localhost:4173/)。

### 背包机甲 · Backpack Mecha

```sh
cd backpack-mecha/game
npm ci
npm run build
npm run dev
```

启动后打开 [http://localhost:4174/](http://localhost:4174/)。

软糖分流与背包机甲的服务读取 `dist/`；修改源码后需要重新构建并刷新页面。三个游戏都应通过 HTTP / HTTPS 访问，不要直接双击 HTML 文件。

手机访问本机服务时，应与电脑连接同一局域网，并使用电脑的局域网 IP 替换 `localhost`：新启程启动命令追加 `--lan`，背包机甲使用 `HOST=0.0.0.0 npm run dev`，软糖分流的开发服务默认支持局域网访问。不同浏览器、设备、端口和线上域名的本地存档相互独立。

## 更新 GitHub Pages 试玩

当前 GitHub Pages 从 `main` 分支的仓库根目录发布。三个试玩链接分别对应仓库中的静态 `dist/` 目录；软糖分流与背包机甲的构建产物也纳入 Git 管理。两款游戏的脚本、样式、图集均使用相对路径，支持上表中的仓库子目录，无需账号或后端服务。

修改软糖分流或背包机甲后，在仓库根目录重新构建：

```sh
npm --prefix jelly-flow ci
npm --prefix jelly-flow run build
npm --prefix backpack-mecha/game ci
npm --prefix backpack-mecha/game run build
```

检查变更，将源码和对应 `dist/` 一起提交并推送到 `main`。等待仓库 Actions 中的 `pages build and deployment` 成功后，线上试玩才会更新；仅执行本地构建或提交不会发布。

三个游戏由本仓库统一管理，不要在游戏目录内初始化独立 Git 仓库。此前 Sites 域名下的本地存档不会自动迁移到 GitHub Pages。
