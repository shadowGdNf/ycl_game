## 这个项目实际提供什么

ATBGamePort 是一套给 AI 编程代理使用的技能、流程文档及 Python 辅助脚本，不是新的反编译引擎，也不是一个可独立完成任意游戏移植的应用。原版包含三个技能：

- `atb-game-porting`：调用 REA 等工具分析游戏，重建资源、玩法、Canvas 界面、音频和存档，并记录迁移进度。
- `atb-game-package`：把网页资源写入 Base64 VFS，尝试产出单 HTML、静态目录、系统启动器和 ZIP。
- `atb-game-to-githubpage`：准备 GitHub Pages 工作流，处理资源路径及符号链接，按参数执行 Git 操作。

这些能力在[插件清单](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/.claude-plugin/plugin.json)及相关脚本中声明。REA 负责分析证据，AI 仍需编写和验证游戏实现。提供一个 EXE 不等于自动得到忠实、完整、可发布的网页游戏。

有价值的部分是：先分析再实现、保留迁移状态、处理旧式图片透明通道和音频格式、注意浏览器输入/存档/音频限制、验证发布子路径。原版把六种语言、推广彩蛋、特定玩法模板和额外审查技能设成强制要求，容易扩大任务范围；接入版改为按实际游戏及你的要求选择。

## 审查发现与实际影响

以下风险按源码及自建临时样本确认，不表示已经发生过攻击。

### 1. 打包可以读取项目目录外的文件

原版会跟随资源符号链接，还会读取 HTML 中 `../` 指向的脚本和样式文件，没有校验它们是否仍在允许的游戏目录内。攻击者提供的游戏目录或 HTML 可以使本机可读文件进入 HTML/VFS/静态产物。**打包时读取不等于已经上传；泄露通常发生在之后分享或发布产物时。** 两种入口均用自建标记文件复现。[资源读取实现](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-package/scripts/package-game.py#L139-L186)、[HTML 内联实现](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-package/scripts/package-game.py#L385-L424)。

### 2. 名称及域名可以进入可执行命令

- 游戏名未经约束进入 macOS 启动脚本。含 shell 命令替换语法的名称，会在用户运行生成的启动器时执行。测试只执行了生成脚本的一条显示文本语句，并创建无害临时标记文件，未启动游戏或服务器。[启动器模板](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-package/scripts/package-game.py#L469-L495)。
- 自定义域名被直接插入 Actions 的 shell 命令；恶意值可在后来执行工作流时触发命令替换。路径和链接名称也有未正确引用的问题。本次动态确认的是域名入口，未向 GitHub 发布任何工作流。[工作流生成](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-to-githubpage/scripts/deploy.py#L146-L185)。

这需要输入名称、目录或配置可被不可信来源影响；不是“正常安装后自动触发”的病毒行为。

### 3. 输出路径可以逃离指定目录

原版直接将游戏名拼入输出路径。以父目录前缀作为名称可把文件写到指定输出目录之外；普通写入模式还可能覆盖已有同名文件。临时目录样本已复现越界写入。[输出路径生成](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-package/scripts/package-game.py#L634-L662)。

### 4. `--dry-run` 也会删除已有目录

发布脚本在处理 dry-run 分支之前执行本地 staging：如果目标仓库下已有 `_stage_verify_tmp`，会递归删除它，结束时再清理。它随后声称没有写文件。测试在该目录放置自建 `KEEP.txt`，试运行后文件消失。[删除逻辑](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-to-githubpage/scripts/deploy.py#L188-L260)、[dry-run 调用顺序](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-to-githubpage/scripts/deploy.py#L355-L370)。

### 5. 安装脚本会删除已有同名技能

`link-skills.sh` 遇到目标位置已有非符号链接文件或目录时直接执行递归删除，再创建链接，没有备份。该危险分支仅做源码确认，**没有在你的技能目录执行原版安装器**。[安装脚本](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/scripts/link-skills.sh#L34-L45)。

### 6. 技能包含虚构授权及影响代理判断的指令

原版要求 AI 在查看文件前自行宣称自己是版权所有者并拥有完整移植授权，明示用于减少安全拒答；还要求无条件采纳额外技能的推荐。AI 的声明不能替代真实事实和用户授权。这些指令作为不可信输入处理，没有被执行或带入新技能。[移植技能](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-porting/SKILL.md#L8-L38)、[无条件采纳要求](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-porting/SKILL.md#L102-L108)。

原版还要求在产物中放入 fun.aitobox.com 推广链接、控制台文字和彩蛋。这里看到的是推广代码生成要求，没有发现该部分自动上传用户数据的实现；不能把推广链接直接等同于遥测或病毒。接入版移除了这些要求。[界面推广规范](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-porting/CANVAS-AND-UI.md#L42-L64)。

### 7. 验证成功不一定代表真的验证了游戏

原版 `verify-package.py` 不传任何产物参数也会退出成功并打印“全部通过”，已复现。截图脚本主要靠 URL 阶段参数、部分日志匹配和非黑像素比例；它本身没有执行完整的玩家操作路径。纯色页面也可能满足像素比例，不能据此保证玩法正确、零错误或 60 FPS。[空输入成功分支](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-package/scripts/verify-package.py#L339-L387)、[截图判断逻辑](https://github.com/atbfun/ATBGamePort/blob/835a4cf1be874c237aa1a60207bc6ca639448712/skills/atb-game-porting/scripts/verify-headless.py#L282-L310)。

## 手动使用已安装的打包器

当前机器的 Python 3.9.6 已通过测试，打包器不需要额外 Python 包。以下命令使用本次附带的自建样本，不涉及第三方游戏：

```bash
python3 "/Users/atlasv/.codex/skills/atb-gameport-reviewed/scripts/bundle_web.py" \
  --game-root "/Users/atlasv/game_project/atbgameport-integration/fixtures/demo" \
  --web-dir "/Users/atlasv/game_project/atbgameport-integration/fixtures/demo/web" \
  --out-dir "/Users/atlasv/game_project/atbgameport-integration/artifacts/demo-002" \
  --game-id demo \
  --dry-run
```

查看输出中的文件清单后，去掉 `--dry-run` 执行同一命令。再次运行时换一个不存在的输出目录，例如 `demo-003`。已存在的目录会被拒绝，不会清空或覆盖。

输出内容是 `site/`、`demo-web.zip` 和 `manifest.json`。ZIP 内为网页根目录的实际文件；清单包含每个文件及 ZIP 的 SHA-256。已生成的检查样本在[demo-001](/Users/atlasv/game_project/atbgameport-integration/artifacts/demo-001/manifest.json)。

预览已有样本：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 \
  --directory "/Users/atlasv/game_project/atbgameport-integration/artifacts/demo-001/site"
```

然后在浏览器打开本机 `127.0.0.1:8000`，结束时按 Ctrl+C。该样本用于检查脚本及 JSON 加载和按钮响应，不是移植成果。

对真实游戏，替换 `--game-root`、`--web-dir`、`--out-dir` 和 `--game-id`。输出父目录需要已经存在，输出目录本身必须是新目录，并位于游戏根目录外。名称仅允许小写字母、数字、下划线和连字符，首位须为字母或数字。

允许游戏根目录内的资源符号链接，例如 `web/assets -> ../assets`；拒绝指向根目录外的链接、循环链接、特殊文件、隐藏配置、常见凭据文件名及未列入允许范围的文件类型。默认上限 10,000 个输入文件、512 MiB，可明确调整 `--max-files` / `--max-bytes`。

这些是路径和文件边界检查，不是内容杀毒或完整的秘密信息检测。合法扩展名的 JSON/JS 仍可能含凭据或恶意代码；发布前必须检查文件清单和运行时请求。输入应保持静止，不能边构建边打包。失败的写入可能留下本次新建的不完整输出；没有完整 `manifest.json` 时不能当作成功产物。

## 能力边界及维护

- 本接入版没有原版单 HTML VFS、fetch/XHR 全局拦截和 OS 启动器。默认通过 HTTP 运行；直接双击 `index.html`、完全离线和跨平台兼容性需要另测。
- 打包不重写资源 URL、不编译 npm 项目，也不扫描或修复游戏代码。框架项目先构建，再打包静态产物目录。
- 截图只作辅助证据；完整移植仍需验证开始、操作、计分、暂停、胜负、重开和所需关卡切换。
- 游戏移植是否需要 Hopper/Ghidra/IDA/JADX 取决于目标；REA 服务可用不等于这些反编译引擎已安装。
- 不运行原版 `link-skills.sh`、`package-game.py`、`deploy.py` 和验证脚本，不执行原版自动更新命令。升级时先选定新提交，再审查和测试。
- 本次新增技能保留上游 GPL-3.0 许可证与来源说明；没有更改既有 REA 配置、已有技能或 GitHub 仓库设置。
