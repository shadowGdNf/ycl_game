# 新启程 · 网页战役

基于用户提供的「新启程.apk」制作的可玩浏览器重构版，支持电脑鼠标 / 键盘、手机触屏及横竖屏布局。复用原 APK 的画面、动画、音频、18 关地图、路径、塔位与普通波次配置。

**当前不是原 APK 的完整等价移植。** 原程序是 LÖVE + LuaJIT，关键脚本无法完整反编译，浏览器运行层由 JavaScript 重新实现。现已实现四类基础塔（1–4级，受关卡限制）、杰拉尔德、火雨、援军、战役胜败、逐关解锁和通关星级存档。敌人特殊能力、Boss 分阶段与场景机关、英雄被动、扩展塔和技能树、剧情、其他挑战模式尚未完整还原。后期关卡的平衡不应视为与原版一致。

## 启动

需要 Python 3.9 或以上；运行时不需要 npm 安装。Mac 可双击项目根目录的 `启动新启程网页版.command`，启动已验证的发布副本。

```sh
cd /Users/atlasv/game_project
python3 target/xinqicheng/serve.py --port 8765 --lan
```

电脑访问 `http://127.0.0.1:8765`。手机连接同一个 Wi-Fi，访问启动终端打印的局域网地址。关闭终端或按 Ctrl+C 会停止服务。

静态压缩包解压后，也可以在解压目录运行 `python3 -m http.server 8765`，或者把目录中的文件部署到支持静态文件的网页服务器。网页必须通过 HTTP / HTTPS 访问，直接双击 HTML 不受支持。所有资源使用相对路径，可部署在子目录。

## 操作

- 点击金色建造点建立防御塔；选中已建塔可升级、出售，兵营可调整集结点。
- 点击英雄 / 火雨 / 援军，再点击战场目标。手机可双指缩放，或用右下角 ＋ / −；放大后拖动地图。
- 电脑快捷键：1–4 建塔、Q 火雨、W 援军、E 英雄、N 下一波、空格 / P 暂停、Esc 取消。
- 页面切到后台会自动暂停。速度按钮在 1× / 2× / 3× 之间切换。
- 星级存在当前浏览器和当前网页地址中；换设备或换端口前，可在远征地图导出进度，再导入。战斗中途不保存。

## 文件

- `web/`：可编辑源码和转换资源；其中 `qa.html` / `qa.js` 仅用于开发校验，不进入发布包。
- `dist/`：发布时生成的静态快照；仅包含运行文件和素材。
- `analysis/`：逆向证据、数据来源、限制和验证截图。
- `MIGRATE.md`：逆向路线、移植范围及交付验证索引。
- `tools/build_web.py`：按白名单生成静态快照。
- `tests/`：运行逻辑回归测试，使用 `node --test target/xinqicheng/tests/*.test.mjs` 执行。

原始 APK 保持不变。网页不调用原游戏账户、支付或统计服务，没有把 APK、原生库、工具仓库、反编译输出或玩家存档放入发布包。未声明离线缓存能力；没有 Service Worker。
