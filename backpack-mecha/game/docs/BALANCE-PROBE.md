# 按章节约束的真实战斗探针

版本：visible-state-reactive-v1-chapter-legal。完成：2026-10-26T13:35:42.039Z。

本版替代此前180场报告：保留原有三章终局构筑，补齐第一、第二章的自然等级与预算约束。18套章节配置各挑战该章两个Boss，各10固定种子，共360场；另追加两章版三流派对B2A各10场，共30场。最终总计390场。策略与战斗规则未因胜率调整。

- 第一章所有模块为I级C/U，使用初始可选拾荒者，无协议。磁轨炮W07、导弹架W10均延后到第二章；第一章对应实弹和燃油过渡构筑。
- 无人机巢W11和指令中继S10属于U，当前第一章商店池确实可出现。第一章只用一座机巢；两巢编队从第二章开始。没有借用稀有模块或提前解锁机体。
- 第二章六套配置最高II级且统一使用拾荒者。堡垒构筑增加II级电池以满足电力；冰霜构筑移除瞄准镜，使费用与电力均落在当章限制内。
- 第三章沿用设计稿终局机体、等级、两项协议与装备；游隼、堡垒和蜂巢按此前账户已解锁处理，不能代表首次新账户的单局。
- 脚本逐套断言模块稀有度、等级、协议数量、购买升级成本、装配占格、电力与真实背包合法性。autoPack后还断言支持模块仍连接指定武器。

## 方法与边界

- 实际调用createBattle和stepBattle，每次推进1/60游戏秒；策略每0.1秒决策。没有修改HP、加无敌、直接设胜利、跳过规则、修改伤害或游戏内时间倍率。无渲染运行省去了墙钟等待，不改变模拟步长。
- 只观察960×720世界单位视野内的敌人、已出现预警和敌方弹丸；排除exposed=false货舱及delay>0预警。根据连续观察估计速度，不读取Boss后续招式计划。
- 预装配置属于合法费用与章节条件的fixture，不是商店获取概率测试。每场从正常机体生命/护盾开始，未模拟前序关卡损耗；也不是完整局通关率。
- 策略在16方向和停留间选择，正常使用冲刺、超载和指定目标。其准确几何判断与10Hz反应优于多数真人，390/390不是玩家胜率，也不证明商业平衡。
- Boss场地无随机障碍，十种子主要覆盖战斗随机流及其引发的操作轨迹差异，不能解释为十张Boss地图。
- 执行前后combat、encounters、economy、content和types的SHA-256一致，源码指纹已保存。
