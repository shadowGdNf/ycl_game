# dev.17：流畅度、动态机库与路线记忆

版本 `0.2.0-dev.17`，战斗规则版本仍为 `0.2.6`。本地源码和 `dist/` 已构建；未提交、推送或发布。

## 本次变化

- 地面与障碍物绘制到一个可复用缓存，章节、几何或地面图集加载状态变化时重建；所有敌人共用一个柔边阴影贴图。缓存只保留一张地面和一张阴影。
- 通过 ResizeObserver 更新画布尺寸，避免每帧读取页面布局；HUD 只有内容变化才替换 DOM。视口外的装饰特效不提交绘制。
- 切后台取消动画帧；暂停画面只在进入暂停、尺寸或设置变化时重画。返回页面、继续战斗重置计时与输入，不补跑后台时间；意外长帧最多补算 3 个固定逻辑步。
- 保存复用 IndexedDB 连接。连接就绪后直接使用 `put` 自带的同步快照，不再先完整克隆一次战报与战斗状态。首次异步打开数据库仍保留调用时快照；多个事务按调用顺序落盘。暂停、blur、visibilitychange 的重复保存被合并。
- 依据持续绘制耗时和前台帧间隔，在 2 / 1.5 / 1 倍像素比之间调整；持续 30 个慢帧才降一级，连续 300 个有余量的帧才恢复一级。负载高时减少装饰细节；敌人、弹丸、伤害、攻击预警及固定规则步长保持原规则。
- 首页加入机甲待机、武器随动、环形平台、环绕模块与指示灯。共用现有图集，无额外图片；Canvas 最多 30 Hz，首页屏外、弹窗遮挡和后台时停止刷新。减少动态效果时显示静态画面。
- 武器增加弹体投影、亮暗面、磁轨光环、等离子分层光束、脉冲空间环、爆炸亮核和抛物线碎屑。没有新增全屏模糊或运行时 3D 引擎。特效仍在危险预警下层。
- 本局手动选择的路线保存为 `preferredRoute`。奖励、事件、刷新续局后保留；第一场和 Boss 战临时采用普通路线，后续可选路关卡恢复偏好。主动切回普通路线会更新偏好；新局从普通路线开始。事件风险仍禁止叠加合同，失败选择不会覆盖偏好。

## 验证

`npm run check`、`npm test`（201/201）、`npm run build`、`npm run bundle:check` 通过。覆盖路线跨奖励/Boss/扩容/存档、事件风险互斥、旧存档、渲染质量降级与恢复，以及所有已登记 Boss 阶段的只读绘制。地面和阴影缓存在跨场景测试中只创建两个画布。

内置浏览器以相同快照交替绘制 dev.16 和 dev.17，画布 780×1200，保留每版每场景 300 个样本，执行两轮；未启用自适应画质采样，避免画质不同造成不公平比较。

| 场景 | dev.16 绘制 P95 | dev.17 绘制 P95 |
|---|---:|---:|
| 第二关自然刷怪，三武器 | 1.4–1.5 ms | 1.4–1.5 ms |
| 60 敌人、100 碎片压力场景 | 1.7 ms | 1.6–1.7 ms |

加强特效后常规绘制开销保持在相近范围，密集场景中位数由约 1.4 ms 降到 1.3 ms。两版仍出现过偶发长帧，不能据此宣称消除所有卡顿；保留原始最大值，没有隐藏异常样本。对照数据见 `qa/dev17-browser.json`。

通过真实应用事件处理器模拟隐藏 1.5 秒、恢复后保持暂停：隐藏前后绘制计数均为 234，恢复只补画一帧到 235，再保持 1 秒仍为 235，战斗倒计时一直为 00:38。连续两次保存后再修改内存对象，回读保留第二次调用时的 456 碎片，没有写入之后的 999。

另检查 320×700 装配路线布局、390×844 首页、桌面首页、减少动态效果、保存回首页再继续。截图和浏览器记录在 `qa/dev17-*`。这些结果是桌面内置浏览器检查，模拟后台事件不等于手机操作系统挂起；Android/iPhone 真机持续帧率与自然完整十二场仍待验收。

## 复现

构建后运行 `node scripts/serve-dev17.mjs`，打开 `http://localhost:4202/`。该端口独立使用测试存档，不影响 4174 或线上存档。对照版本默认为 `/private/tmp/mecha-dev16-baseline/dist`，也可通过 `MECHA_BASELINE=/path/to/dev16/game` 指定。验收页和插桩均不进入生产 `dist/`。
