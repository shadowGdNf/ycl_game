# dev.10 · 成长、自由装配与小怪动作

工作版本 `0.2.0-dev.10`，规则版本 `0.2.2`。沿用当前 GitHub Pages 项目，源码与 `dist/` 同步构建；本批未推送或部署。

## 成长与掉落

- 商店和新战利品共用关卡稀有度曲线。精良在第 2 场开放（12%），史诗在第 5 场开放（6%），传说在第 9 场开放（4%）。第 12 场为普通 26%、精良 38%、史诗 26%、传说 10%。
- 战利品在选项生成时固定品质，并随存档保存。旧奖励缺少品质数据时按普通处理。锁定商店商品不重抽。
- 每点刷怪成本的碎片价值为 `0.4 + 0.12 × (wave - 1)`，关卡限制在 1–12。第 1/5/9/11 场分别为 0.4/0.88/1.36/1.6，确保同种怪越往后越值钱；实际掉落允许小数，与原有拾取结算一致。
- 结算上限同步采用本场有效出怪预算乘单价，避免新掉落被旧的低上限截断。召唤、分裂子怪和无奖励增援仍为零掉落；基础通关奖励另外计入。

## 整理与出击

整理只解决空间和连接，不要求背包已具备开战条件。搜索优先尝试连接，再允许部分支持失效，并保留原有效布局作为兜底；连接搜索与纯空间搜索有独立节点限额。不会出售、删除模块或自动拿取备件。保留现有有效连接数，支持撤销。

出击继续检查武器、电力、占格、重叠和数量限制。未连接、不相邻、标签不符、连接位已满等支持件改为警告：列出名称、具体原因和调整建议，玩家可返回调整或点击「仍然出击」。首领试炼采用同样流程。

战斗通过共享的有效连接判定读取支持收益。即使有旧的或错误的 `link` 字段，失效配件也不会偷偷加成；有效配件和其他装备正常工作。失效配件仍占格、耗电。

## 敌人与动作

三章远征从 12 种小怪扩为 16 种，图鉴增加对应战术和 12 个精英变体，总精英变体 48 个。教学档位保留原怪物池。

| 小怪 | 最早出现 | 攻击与应对 |
| --- | --- | --- |
| 侧刃游猎者 | 第 2 场 | 绕侧接近；0.6 秒窄线预警后短距突进，可侧闪或诱导撞墙 |
| 长针狙击手 | 第 3 场 | 1.25 秒锁定后发射高速单弹，横移或用掩体避开 |
| 熔渣布雷车 | 第 5 场 | 1.2 秒预警后布置两侧雷区，持续 2.2 秒，中间留出通道 |
| 环波哨兵 | 第 7 场 | 1 秒蓄力后射出十枚环形慢弹，从间隙穿行 |

敌人增加独立活动硬件：侧刃开合、长炮管后坐、雷仓伸缩、环架旋转与蓄能。玩家增加膝部连杆、脚步接地、背包惯性、武器支架随动。射击后坐按照实际开火事件衰减，位移动作根据移动距离推进；减少动态效果设置关闭装饰性晃动，保留危险提示。

本批使用现有底盘图集和 Canvas 分层硬件，没有新增真实 3D 模型或逐帧动画图片。

## 验证与复现

- `npm run check`、`npm test`、`npm run build`、`npm run bundle:check`。
- 151 项自动测试全部通过。自动回归包括成长概率、实际击杀到拾取结算、奖励品质续存、空间整理与原子失败、失效原因和真实支持收益、四类新怪预警/释放与快照续战；输出 `qa/dev10-tests.txt`。
- `node scripts/serve-dev10.mjs` 在独立 `http://localhost:4200/` 提供动作预览和不兼容配件验收存档。点击按钮才写该端口的测试存档，不接触正常 4174 或线上存档；QA 页面不进入 `dist/`。
- 内置浏览器完成整理→出击警告→返回调整→再次出击→确认进入战斗→结算，控制台无错误。390×844 视口下提示和两个操作按钮可见；这属于布局检查，不是真机验收。
- 动作预览可查看四类新敌人和移动/冲刺/开火机甲，支持暂停与减少动态。局部预览的渲染数据不能代替高密度完整战场性能。
- `qa/dev10-natural-smoke.json` 是六种路线、各一个种子的真实商店成长机器冒烟结果：六局均跑完 12 场，共通过 72 次存档续战对照；没有发现非有限数值或模拟超时。不能解释为真人胜率或完整平衡验收。

Android / iOS 真机和更大样本难度平衡仍待验收。旧快照中已生成的怪物奖励和预警保留原值，后续刷怪采用新规则。
