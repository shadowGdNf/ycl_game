# 背包机甲美术与动作交付

本版本使用内置 `image_gen`，以 `assets/source/art-direction.png` 为统一风格参考，生成真实透明栅格图集。所有完整提示见 `ASSET-PROMPTS.txt`。保留原始像素，未离线改色、抠图或重新绘制；Canvas 在运行时按图集元数据采样。

## 风格基线

- 固定三分之四俯视的手绘工业玩具造型；短腿、大背包、机械连接件和清晰深色轮廓。
- 友方采用奶油白 `#E8DFC9`、橙色 `#F39443`，能源青 `#48D1C4`；敌方采用锈红、深灰和橙红灯；背景维持低饱和蓝灰。
- 素材与 UI 均保留同一视觉语言。稀有度、敌方预警和状态不只靠颜色传达。

## 角色与动作

- 身体按移动方向切换下、右、上、左四个朝向；静止保持最近朝向。腿、背包与躯干独立合成，背向时将背包绘制到躯干上方。
- 每机体共用左、右、上方三个武器挂点；武器独立朝向其目标。装备按稳定实例 ID 分配挂点，战斗中不重新分配。
- 行走的下、右、上、左四方向各定义四个明确程序姿态：触地、经过、另一脚触地、另一脚经过。每0.48秒循环一次，姿态间采用平滑插值；左右腿分别插值位移与角度，并带动轻微躯干起伏。
- 腿部仍使用现有栅格腿对，在运行时按腰部中线分别采样和变换；侧向步态略收窄。这里交付的是16个方向程序姿态，没有新增或宣称16张手绘动画帧。身体方向仍由移动决定，静止保留最近朝向，武器挂点保持不变。
- 待机使用低幅呼吸；武器使用0.13秒程序后坐力。震荡锤有挥动角，圆锯独立旋转，无人机以独立挂件绕行。
- 冲刺有短距离残影和倾斜；死亡采用六个程序姿态，约0.43秒完成，界面保留0.65秒展示。减少动态效果模式使用静止腿部姿态、关闭残影与摆动，死亡终姿态展示0.12秒，保留所有危险提示。
- 碰撞与伤害绝不从图像边界或动画帧推导。程序视觉尺寸不会改变角色半径14的规则。

## 渲染约定

`Renderer` 提供 `load`、`draw`、`preview`、`icon`、`portrait` 与 `toWorld`。`BattleView` 是只读快照；Canvas 不修改战斗数据。

- 世界视野短边为720世界单位，设备像素比最高2；摄像机跟随玩家并限制在场地范围内。
- circle/ring以位置为圆心，cone以位置为顶点；rect/line以位置为长轴起点，沿angle延伸w，h为宽度。
- `delay > 0` 的区域尚未开始提示，不绘制；危险预警永远在友方特效上层。
- 电弧使用事件起点与 `targetId` 指定的敌人坐标。状态、子弹、掉落、失衡和边缘威胁单独呈现；主Boss条和章节信息由DOM界面绘制。
- 双子每个实体仅显示一个机体；母舰隐藏未展开的货舱，展开后分别显示左右部件。无人机数量跟随战斗的 `droneCount`，不在渲染层另算规则。
- 必要图集约6.69 MB；2.71 MB地面仅进入战斗后异步加载。地面未就绪时使用同色平面，不遮挡角色与预警。
- 素材加载失败会使 `load()` 拒绝，由主界面提示并提供重试；地面属于装饰资源，失败不影响规则运行。
