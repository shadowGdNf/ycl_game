# dev.9 · Boss 攻击节奏与弹幕强化

2026-10-29。应用 `0.2.0-dev.9`，规则 `0.2.1`。本批增强全部六个 Boss，源码、图鉴和 `dist/` 已同步。未推送或部署 GitHub Pages。

## 改动

常规招式后摇从原先的 1–3 秒缩短到约 0.6–1 秒；高警戒、后期阶段与过载继续缩短，最低保留 0.4 秒。主动攻击仍有完整预警，主要起手至少 0.8 秒，回收者扩散环为 0.6 秒。旧版高警戒偶尔跳过招式的逻辑改为保持完整循环，通过弹速与后摇增加压力。

| Boss | 新行为 |
|---|---|
| 压路王 | 基础冲锋速度 400→540；废料落点 3→5/7，追加 5/7 发扇形弹；重砸更快。冲锋提速时同步缩短持续时间，保持行进距离在预警范围内。 |
| 磁吸起重机 | 牵引速度 60→85，摆锤扫过时间 1.5→1.25 秒；召唤时追加 6/8 发磁屑弹，第二阶段更多钉虫。 |
| 熔炉蟹 | 5/6/7 处熔渣与 5/7/9 发扇形弹；火地持续时继续释放下一招，喷流后追加三处熔渣。 |
| 磁暴双子 | 脉冲由 4 轮×4 发改为 6 轮×6 发 / 8 轮×8 发；轮间隔 0.4→0.26 秒，交错发射。 |
| 零号回收者 | 激光扫过更快、更宽；抓取追加 7/9/11 发弹幕，扩散环基础速度 190→250；流水线追加三轮七发齐射。 |
| 轨道母舰 | 扫射从 5 轮×9 发增为 6×11 / 7×13 / 8×15，间隔 0.35→0.26 秒；第二阶段增加错位轰炸，护航机与护航齐射增加。 |

弹幕基础速度为 310–350，阶段、警戒与过载提供额外倍率。第一阶段追击速度提高 40%，后续继续增加；最慢机体仍能以基础步行速度拉开与普通追击的距离。冲锋是单独的高速技能，需要横向躲避。

保留压路王撞墙的两秒硬直、起重机内圈、母舰轰炸的两条安全通道和扫射的 60 度安全扇区。普通与传说装备的数值、Boss 生命和共享生命伤害去重没有改动。

## 验证

`npm run check`、`npm test`（140/140）、`npm run build`、`npm run bundle:check` 通过。新增回归覆盖所有 Boss 的五档警戒、弹幕数量和弹间距、真实弹速、冲锋预警与距离、火地期间接招、实体数量上限、过载、存档重载和确定性续战。

每个 Boss 最终阶段、标准难度下，按六轮完整招式计划计算：

| Boss | 每分钟招式组：旧→新 | 每分钟计划弹数：旧→新 | 平均弹速：旧→新 |

| 压路王 | 14.24→22.37 | 0→52.20 | 无→334.8 |
| 起重机 | 14.47→17.41 | 0→46.42 | 无→345.6 |
| 熔炉蟹 | 9.22→22.81 | 0→68.43 | 无→382.8 |
| 磁暴双子 | 19.52→21.14 | 104.12→450.95 | 220→356.4 |
| 零号回收者 | 7.50→13.16 | 0→140.35 | 无→406 |

这些是招式时间表指标，不包含被击杀、失衡、撞墙或召唤小怪造成的实战差异。

同时使用同一个可见状态机器操作策略、相同六套试炼预设，对全部六个 Boss 测试精良与传说装备。旧版与新版各 72 场，标准难度、基础电力 18；正常生命与伤害规则，没有无敌或直接扣 Boss 血。结果如下：

| 装备档位 | 旧版胜场 | 新版胜场 | 旧版平均承伤 | 新版平均承伤 |
|---|---:|---:|---:|---:|
| 精良 | 34/36 | 31/36 | 37.25 | 95.25 |
| 传说 | 36/36 | 35/36 | 23.03 | 54.43 |

承伤可以高于生命上限，因为护盾会回复。精良冰霜单武器预设对第三章两个 Boss 在旧版和新版都触发 300 秒游戏限时；新版传说冰霜对母舰也触发限时。其余新增失败为正常战败。测试反映攻势增强，不代表真人胜率，也不证明随机商店能凑出相同配置。未为了提高机器胜率削弱 Boss。

独立压力场景采用无武器、明确标注的无敌状态，固定最终阶段、警戒 4，测量 45 秒弹幕与区域数量。另有 60 秒的单位测试检查弹丸少于 180、区域少于 40、敌人不超过 70，且没有非有限坐标。压力场景不参与上述胜率统计。

在桌面内置浏览器的 390×844 视口检查母舰和双子密集弹幕：图形、蓄能预警与安全区可见，控制台无错误/警告。母舰场景采样 601 帧，帧间隔 p95 为 17.2ms，渲染耗时 p95 为 1ms，未出现超过 50ms 的采样；这是电脑上的手机视口数据，不是 Android Chrome 真机性能结论。

## 维护与复现

攻击规则位于 `src/encounters.ts`，战斗调度位于 `src/combat.ts`。图鉴文案位于 `assets/source/boss-guide-dev9.json`；`scripts/export-content.py` 合并文案覆盖后生成目录，保留原始设计基线。

存档格式不变。旧战斗快照中的已排队攻击保持原样，下一组攻击使用新规则。恢复后仍按新版本追击速度计算，不锁定旧数值。

```sh
npm test
node --experimental-strip-types scripts/boss-pressure-probe.ts
node scripts/serve-feedback.mjs
```

反馈服务打开 `http://localhost:4198/`，选择“双子 / 母舰 · 最终阶段弹幕验收”。场景不写存档。正常游戏可从首页首领试炼场直接体验强化后的 Boss。

探针对照可追加 `--baseline=/path/to/old-game`，旧目录需要 `src/` 与 ESM `package.json`。本轮旧版副本取自修改前干净工作区；对照数据已保存在 JSON，重新运行当前版不要求该临时副本存在。
