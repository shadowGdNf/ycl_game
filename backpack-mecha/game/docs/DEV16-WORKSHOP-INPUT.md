# dev.16 · 拖放、休整确认与首领装配

版本 `0.2.0-dev.16`，规则版本 `0.2.6`。沿用 dev.15 动态效果，已更新本地构建，尚未推送或部署。

## 拖放更宽容

拖动记录抓取点在模块内的连续坐标，不再使用按下格 / 松手格直接相减。落点寻找附近合法摆放，兼容自动转向；整件装备的每个占格都可作为互换目标。候选范围有限，拖出背包较远会取消放置，不会跳到另一端空位。

拖动和松手使用同一套预览与提交逻辑，释放时重新读取最终指针坐标。点击其他模块仍可互换；开始拖动另一件模块时，不会在按下瞬间执行互换。取消拖动不修改装备；移动与互换仍支持撤销。首领试炼共享落点解析器。

## 默认商店与未消费确认

战斗结束进入休整、从首页继续休整时，默认选中商店，并清空上次操作的选择状态。同一休整页内切换标签或编辑装备时，保留玩家当前标签。

用户确认的规则：本次休整 **没花过任何碎片** 就出击时，询问是否不买装备直接进入下一关，可返回商店或明确继续。购买、购买合成、刷新、维修、付费事件均会记录本场消费；失败操作、免费整理 / 合成 / 升级、出售不算消费。消费记录随存档保存，下一次休整重新判断；首场与隔离首领试炼不提示。若另有失效配件，将其原因一起放入确认框，避免连续确认。

消费标记存储在兼容的 `Run.extra.spentPrepWave`；旧存档缺少标记时，可参考同场战报中的成功付费操作。撤销回滚经济快照时，也回滚对应消费标记。

## 首领试炼可编辑大背包

- 桌面双栏：左侧背包、位置操作和连接，右侧模块目录。
- 手机单栏：背包保持可操作大小，模块目录在下方独立滚动；开战按钮固定在弹窗底部。
- 桌面实测背包宽 450 px；390 px 视口为 326 px，320 px 视口为 256 px（旧版手机预览仅 96 px）。
- 支持拖动、点选移动 / 互换、旋转、整理、手动选择连接、移除、清空和一步撤销。
- 自定义布局直接作为首领战装配。切换首领、机体、难度、品质和电力不会自动重新整理；本次会话内退出再进 / 再战继续保留布局。切换预设会生成该预设的新布局。刷新页面后的试炼配置仍为默认值。
- 新增模块仅尝试填入空位，保留已有模块位置；放不下时提示先整理或移除。非法装配不能开战，远征存档继续隔离。
