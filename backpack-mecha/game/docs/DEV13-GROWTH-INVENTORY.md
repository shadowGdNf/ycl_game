# dev.13 · 武器、机体成长与背包交互

当前构建 `0.2.0-dev.13`，规则 `0.2.5`。本地源码与 `dist/` 已更新，本轮未推送 GitHub Pages。

## 内容

武器从 12 种扩充到 18 种，总模块 42 件。新增转轮机枪、等离子光矛、特斯拉脉冲、冰晶霰射器、燃烧迫击炮、突击蜂群。新增武器各自执行高速单弹、光束贯穿、电伤环击、冰弹散射、燃烧范围爆炸和三机召唤；支持相关标签配件、四档稀有度、合成、商店、战利品、图鉴与首领试炼。

新模块目录保存在 `assets/source/weapons-dev13.json`，由 `export-content.py` 合并到两个运行目录，重新导出不会丢失新增内容。美术复用原图集底盘，叠加不同炮管、光刃、线圈与蜂群标记；没有声称新增六套独立生成原画。光束、脉冲、冰弹和无人机有对应战斗表现及音色。

## 成长

每次远征从 Lv.1 开始，最高 Lv.12。经验在胜利结算事务中发放，重复结算和失败不发放经验。每级自动提升三项基础属性，并提供一点自由专精，具体公式和四角色成长见 README。生命成长只回复新增上限；维修、事件、协议回复均尊重新上限。基础攻击乘到统一伤害入口，基础攻速乘到武器冷却，蜂巢援护技能同步成长。最高等级不会继续积累经验或点数。

`Run.growth` 随原 IndexedDB 存档保存；旧存档按 Lv.1 继续，旧战斗补齐倍率 1。无效可选成长字段回退为初始值，核心远征保持。战报附带成长快照。升级分配清除可能回滚分配结果的旧出售撤销记录。

## 背包

放置预览与提交共用同一计划，尝试当前及其余朝向。成功前不修改原局，因此互换失败不会丢失装备、链接、碎片或随机流。

- 备件自动装入：找空位、自动旋转、尽量连接，不挤出其他模块。
- 点选 / 拖动到已有模块：按目标模块整体互换；点击目标任意占格均可。
- 满备件与背包互换：原背包模块进入备件，容量不变。
- 拖到备件区或快捷按钮卸下；满架不能单独卸下，仍可互换。
- 边缘放置尝试贴边；原地旋转失败保留待放置朝向，允许选新位置。
- 悬停 / 拖动显示完整占格，互换和自动旋转有不同标记。
- 移动、卸下、旋转、互换、整理及直接放置购买可撤销一步；Esc / × 取消选择。
- 空间编辑允许暂时超电力，出击仍校验电力、武器数量和重复限制。
