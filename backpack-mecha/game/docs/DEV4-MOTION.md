# v0.2.0-dev.4：战斗动作与验证记录

开发日期：2026-10-27。规则版本仍为 `0.1.0`。本版完成动作核心开发；独立浏览器的完整远征及设备验收保留待测，不能据此标记 v0.2 正式发行通过。任务来源为 [DEV4-PLAN.md](DEV4-PLAN.md)。

## 实际改动

`motion.ts` 将当前战斗快照投影为准备、生效、恢复、控制和弱点信息。动作只读取逻辑时间、当前区域、来源实体、延迟、冲锋和弱点时间；不使用自己的攻击计时，不消费随机流，不更改 AI 或碰撞。一次渲染集中生成实体动作信息。

| 对象 | 本版表现 | 同步边界 |
|---|---|---|
| E05 自爆电池 | 顶盖抬起、蓄能格、爆炸消失事件 | 随原有 0.8 秒预警；提前死亡取消区域；不新增伤害或奖励 |
| E12 清扫车、B1A 压路王 | 车体压低、方向箭头、推进尾迹、机械停顿 | 跟随现有预警和冲锋；延迟第二冲尚未开始时不显示准备；撞墙状态有独立括线，失效路径移除；虚线为行进预告、实线圆为当前冲锋碰撞范围 |
| B1B 起重机 | 上臂摆动、牵引箭头、当前扫击方向 | 扫击内圈保持透明，范围与 `contains` 一致；牵引使用虚点边界和内向箭头 |
| B2A 熔炉蟹 | 炉门蓄热、左右开合、弱点光标 | 仅在真实 `vulnerableUntil` 窗口显示“弱点暴露” |
| B2B 磁轨双子 | 天线蓄能、发射反馈、固定线端点 | 两个身体共享攻击状态；地面连线读取攻击计划坐标，不随身体改写 |
| B3A 回收者 | 双臂收放、光束蓄能和方向、阶段刻度 | 扫向读取当前角度；扩散环仍按实际内外半径绘制 |
| B3B 回收母舰 | 机翼开合、轰炸/齐射指示、侧舱暴露 | 一阶段隐藏不可命中的侧舱；后续阶段按 `exposed` 显示 |

沿用五张图集和 86 个区域，用现有图像的局部分段绘制动作；本版没有新增图片或修改原像素，也没有把整张固定透视素材大幅旋转。

### 控制状态与地面信息

原有 `frozen` 同时承担寒冷冻结、撞墙停止和 Boss 失衡。现在额外保存可缺省的 `controlReason`：冰冻用晶体轮廓，撞墙用机械括线，失衡用十字星；文字同时明确原因。旧续局缺失或非法原因值时，保留有效战斗并显示中性的“行动受限”。停止时长不变。

核对原规则确认：冻结或失衡不会自动取消已经发出的地面区域。画面保留这些仍有效的预警；只有实际死亡等规则条件会取消。不能把身体停止错误解释成地面已安全。

伤害、牵引/输送带和增援分别使用实/虚边界、箭头、加号等提示。非伤害区域先绘制，伤害边界在其上；保留环形与扇形的内部安全区。Boss 的状态标签保持至少 10 CSS 像素并限制在可见边界内，修复上沿裁切导致的提示丢失。减少动态模式停用起伏、命中回弹与冲锋拖影，保留姿态、方向、文字和危险区域。瞬时弹幕在预警移除后使用原有 `enemy-fire` 事件显示 0.18 秒发射姿态，之后由弹丸承担危险提示。

## 规则与兼容性证据

- 原有回归与新动作测试覆盖延迟攻击、冰冻期间有效区域、提前死亡、爆炸只发一次、真实寒冷/失衡原因、弱点时限、双子固定连线、扇形内圈、旧存档、渲染不修改快照、边缘标签。
- `qa/dev4-rule-parity.json`：对保留的 dev.3 源码逐帧对照，24 个明确标注的场景、43,200 帧通过。规则比较只排除展示原因与事件计数；原有事件除 ID 外另行逐项比较，仅允许新增 `enemy-explosion`。位置、AI、随机流、伤害、资源及所有其他字段均一致。
- `qa/dev4-natural-comparison.json`：六路线各 10 种子，共 60 局、720 场、720 次战中恢复；完整战报（购买、逐场经济、装备、伤害和胜负）复现 dev.3。只排除构建版本和可选的成长搜索诊断字段。当前机器策略 60/60 获胜，不代表真人胜率。
- 保留 dev.3 报告和发布包，不覆盖历史自然探针。探针默认文件名现在跟随构建版本；也支持显式 `--output`。

最终自动回归为 **84/84 通过**，场景预览含 **106 个状态**，三种视口分别完成全部状态的渲染冒烟检查。汇总数量、运行日志、文件指纹和最终状态见 `qa/dev4-check.json`。

## 网页证据的口径

开发夹具与正式网页使用独立来源。夹具页不加载游戏应用，不打开 IndexedDB，不写入正式存档；页面始终标注“场景夹具”。所有常规 Boss 阶段通过设定合法阶段生命区间后运行真实 `stepBattle` 得到，不计作自然通关。冰冻/旧存档原因和危险叠加另行标注为直接设置或合成场景。

`qa/dev4-motion-scenes.json` 汇总夹具覆盖、浏览器实际渲染记录和截图。按控件遍历全部场景属于渲染冒烟检查，代表截图才属于逐图工程检查；这些均不能推断玩家理解率。视口检查不替代触摸、手机帧率或多指操作。

`qa/dev4-browser-flow.json` 单独记录公开游戏操作、失败尝试和待测项。本版内置浏览器通过正式入口完成 FIRST-LIGHT 首场 40 秒战斗、键盘移动/超载/冲刺、暂停保存、刷新续玩、免费线圈连接及冷冻喷头购买；购买后再刷新保留三件模块、电力 5/10、空间 6/21、碎片 52.8，停在第二场准备页。战报已导出；其中约 6534 秒休整包含工具等待下载的时间，不用于体验节奏结论。内置浏览器结果明确写为 Codex 内置浏览器，不根据 UA 中的 Chrome 字样称为独立 Chrome/Safari。

独立 Chrome 的原生控制初始化超时，未完成操作。Android 仍保留 dev.3 登记的 MIX 2S / Android 10 状态；未完成触摸、声音或后台恢复验收。iPhone Safari 按用户“暂无设备”的回复继续待测。正式跨平台验收要求不因此降低。

正式装配页另外完成 390×844 的中文/英文购买预览，以及 844×390 英文弹窗滚动检查，能读到连接收益并操作底部按钮；返回预览没有额外购买。结束时恢复中文和正常视口，继续保留第二场准备进度。此轮控制台没有警告或错误。这些是桌面视口与鼠标检查。

## 性能与包体

性能预览通过同一浏览器、1280×900 视口和固定场景，对 dev.3 与 dev.4 交替执行各三段样本：每段预热 3 秒，采集 60 秒；顺序覆盖第三章密集敌人、Boss 光束、多区域叠加。固定结果面板和状态栏尺寸，逐段校验画布尺寸不变；前期因结果面板挤占画布的采样已标注作废并保留，不用于通过结论。普通敌人绘制减少重复变换，箭头合并路径，状态文字宽度使用有上限的缓存，完整文字标记最多缓存 48 张离屏位图，不支持离屏 2D 的浏览器回退到直接文字。有效的首轮对照（`dev4-performance-before-label-cache-summary.json`）p95 为 1.0 → 1.2 ms，触发这次绘制缓存优化；保留该结果与源码指纹。原始帧间隔和渲染调用耗时保留在 `qa/dev4-performance.jsonl`，汇总见 `qa/dev4-performance-summary.json`。

最终六段样本均为前台、画布固定 1280×793，dev.3 / dev.4 分别记录 10,802 / 10,803 帧。合并样本的渲染 p50 为 0.4 → 0.5 ms，p95 均约 1.1 ms，未触发 15% 检查线；最长绘制为 1.6 → 3.2 ms。两版帧间隔 p95 均约 18.1 ms，均无超过 50 ms 的记录。各段结果有波动，已完整保留，不能据此声称缓存单独带来了特定幅度的改善。此前另一次采样发现首段画布变化，整个对照已保存在 `dev4-performance-discarded-viewport.jsonl` 并排除；当前夹具还记录尺寸变化的具体值，便于后续诊断。

这是固定快照的 Canvas 渲染成本及前台帧间隔检查。它不包含 20 分钟真机运行、触摸延迟、发热、内存增长，也不证明全部自然战斗场景具有相同性能。带后台切换的样本不能算前台通过。

网页目录为 **9,675,238 字节（约 9.23 MiB）**，较 dev.3 增加 20,528 字节，满足 11 MiB 目标；原有 20 MiB 兜底检查不变。正式包排除预览 HTML、生成夹具、源码素材和本地 QA 接口。图集哈希及 ZIP 的 SHA-256 见检查报告与相邻 `releases/release-manifest-v0.2.0-dev.4.json`。

## 复查方式

```sh
npm run check
npm test
npm run build
npm run art:check
npm run bundle:check
node --experimental-strip-types scripts/natural-probe.ts --policy=legacy --output=natural-probe-dev4-legacy.json
node scripts/compare-motion.mjs
node --experimental-strip-types scripts/motion-fixtures.ts
node scripts/serve-motion.mjs
```

在动作预览点击性能对照并完成各三段采样后，执行 `node scripts/summarize-motion-performance.mjs` 汇总；脚本拒绝不完整、后台或尺寸变化的样本。`python3 scripts/dev4-evidence.py` 校验当前源码与各份证据指纹，再由 `python3 scripts/package-release.py` 生成开发包和清单。

动作预览为 `http://localhost:4196/`，生成的场景在临时目录。性能对照另外需要 dev.3 网页包解压目录（`MECHA_BASELINE_WEB`；默认 `/private/tmp/backpack-mecha-dev4-baseline/web`）；缺少基线只禁用性能按钮，动作预览仍可用。生成目录可用 `MECHA_MOTION_DIR` 配置，须与生成命令参数一致。逐帧规则对照需要 dev.3 源码目录：

```sh
node --experimental-strip-types scripts/motion-parity.ts /path/to/dev3/src/combat.ts
```

使用自然探针和本地 QA 时保留独立文件名和来源。源码打包包含验证脚本和报告；线上试玩不会因本地构建自动更新。
