# dev.14 · Boss 双招组合与可躲避攻击

构建 `0.2.0-dev.14`，规则 `0.2.6`。源码、可运行 `dist/` 和图鉴已同步；本轮没有推送或部署。dev.13 的武器、成长与背包功能保留。

## 招式设计

六个 Boss 各增加三套组合，共 18 套；按「原招式 A → 组合 A → 原招式 B → 组合 B → 原招式 C → 组合 C」交错执行。第二轮部分摆臂 / 缺口反向。原有生命、伤害倍率、弹速倍率与追击速度没有加码。

| Boss | 新组合 | 需要处理的走位变化 |
|---|---|---|
| 压缩机 | 碾压夹击、交叉裂地、震环追击 | 躲冲锋后避开两侧落点；连续锁线；穿缺口再避预判炮击 |
| 磁吊机 | 磁吸吊砸、双臂绞索、电环钩索 | 牵引与侧翼落点；摆臂后直线钩索；缺口与钩索同时判断 |
| 炉蟹 | 分流焚烧、熔墙逼位、炉心开合 | 火流中间穿行后换位；熔墙限制横移；近身爆发后寻找侧向缺口 |
| 风暴双机 | 交叉锁线、双环落雷、夹击电网 | 第二道射线预判行进方向；双环叠加落雷；弹幕与横向电网组合 |
| 零号回收者 | 折返扫描、震环点名、流水线切割 | 两次相反扫描；缺口叠加连续落点；传送带与切割线组合 |
| 轨道母舰 | 棋盘接力、封锁与点名、侧舷交火 | 横纵轰炸切换；弹幕缺口叠加预判落点；双侧舷锁线后轰击 |

第二拍的指定落点可按开招时的行进方向预判。预判只执行一次；预警后不会追踪玩家。持续同向绕圈会进入预测落点，可以急停、折返或侧移。两拍均有独立可见预警，最低 1.15 秒，震环为 1.25 秒；延迟出场不会吞掉预警时间。

HUD 显示招名、①→②和应对提示；地面使用编号和不同颜色区分两拍；第二拍从开招时就以点虚线预览，随后进入完整预警，避免隐藏未来落点。组合后保留 1.1 秒收招，Boss 暂停追击，HUD 提示反击。场上尚未消失的弹丸仍有伤害，因此提示同时提醒保持走位。中英文、减少动态效果模式和手机横竖屏均可显示。

## 避免封死退路

- 扩散环具有真实碰撞缺口，缺口箭头、预警、活动伤害与释放特效使用同一几何定义。新环缺口约 76°；原零号回收者的闭合扩散环改为约 112°缺口，朝场地内侧，不再要求用冲刺无敌穿环。
- 开组合前，在当前场地边界、Boss 接触体积、现存弹丸、残留伤害区、牵引 / 传送带以及新组合之间搜索步行退路。考虑 250ms 反应时间、玩家半径和几何余量，不依赖冲刺、护盾或无敌。
- 扫描 / 扩散的未来位置、弹丸飞行、当前减速和红隼加速到期也进入预测。若找不到路线，先尝试加长预警，仍无路线则延后 0.6 秒重试，不生成攻击、不推进招式序号。
- 初版折返扫描在角落覆盖过宽，依据逃生测试收短了范围。

这是有限候选路线与当前危险状态的检查，不是对任意未来小怪 AI、玩家后续输入和所有连续位置的数学证明。旧招式保留原有完整预警；检查用于新增组合，不会中途更改已经显示的攻击。被小怪堵住时仍需主动清怪和走位。

## 验证

- `qa/dev14-tests.txt`：186 项通过，包含旧战斗、背包、升级、装备、音画与存档回归。
- 新组合：540 组「六 Boss × 三阶段 × 三组合 × 十个中心 / 四角 / 边缘位置」，在最高警戒与过载下，用减速装甲后的壁垒基础速度 174.6 检查步行路线。
- 180 场末阶段场景在实际 60Hz 引擎中回放逃生路线；无武器、无无敌、无冲刺，伤害为零。
- 432 组移动入场场景，检查预判第二拍；本组 432 场均获准开招，回放步行路线无伤通过。另有 36 场减速 / 红隼加速中途到期回放。
- 完全封闭的合成火区验证延后机制，锁定落点验证不追踪，组合中途 JSON 存档续战与原战斗一致，收招期间不会追击。
- `qa/dev14-browser.json`：隔离 Chrome，六 Boss 组合、活动震环缺口、收招提示、触屏暂停、390×844 / 320×740 竖屏、844×390 英文横屏、减少动态效果。截图使用明确的无敌视觉夹具，不是生存证据；没有读取用户实际存档。没有浏览器异常。
- 类型检查、资源检查、构建与静态包检查通过；包约 1.83 MiB，见 `qa/bundle-check.json`。

`qa/dev14-boss-pressure.json` 包含与 dev.13 源码快照的 72 对固定配装机器对照。当前 II 阶 33/36、IV 阶 34/36 获胜，其他均为超时；这不是真人胜率，也不证明所有 Boss 都更难。新版本减少了单纯密集弹幕在循环中的占比，加入空间与转向判断，机器能及时变向时仍然可以躲避。长期难度和成长后装备压制需要真人试玩继续调整，不能据此声称已完成最终平衡。
