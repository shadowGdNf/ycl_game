# dev.11：后期性能、稀有武器价格与机体技能

版本 `0.2.0-dev.11`，规则 `0.2.3`。本地源码与 `dist/` 已更新；没有推送或部署。

## 性能修改

- 玩家弹丸只对实际扫掠碰撞候选排序，保持原先由近到远、同距按实体 ID 的判定顺序。此前每颗子弹每个逻辑帧均排序全部存活敌人。
- 寻路按场景几何、边界和敌人半径缓存网格通行性，复用有界队列；几何变动自动失效，结束场景可由弱引用回收。路线仍按原来的邻接顺序搜索。终点只保留坐标，避免把整份玩家属性复制进每个敌人的路线与存档。
- 跳过视口外的敌人图片、弹丸和碎片绘制，预留动作、标签和拖尾边距。屏外规则照常运行；所有危险区域和屏边威胁提示继续绘制。

`scripts/dev11-performance.ts` 对修改前源码（提交 `d49c42377fceaec041ed20b253c15ad7f58774dd`）和当前源码进行三组逐帧对照：导航、弹幕、母舰。每组360帧，共1,080帧，未使用新技能；随机流、伤害、实体状态与路线坐标一致。新增技能字段和旧路线中冗余玩家属性不参与比较。

Node 24.21.0 合成压力测试，每场景每版本2,160个样本，交替执行先后顺序：

| 场景 | 修改前模拟 P95 | 修改后模拟 P95 |
|---|---:|---:|
| 60敌人导航 | 0.212 ms | 0.151 ms |
| 60敌人、240初始玩家弹丸 | 5.165 ms | 0.776 ms |
| 母舰最终阶段 | 0.0132 ms | 0.0130 ms |

同一内置浏览器、同一场景快照、交替绘制顺序的70敌人/160碎片场景，画布780×1200，每版本270个样本，绘制 P95 由2.0 ms降至1.4 ms。见 `qa/dev11-performance.json`、`qa/dev11-browser-render.json`。这些是合成场景的逻辑/绘制调用耗时，不能换算成手机实际帧率；Android/iPhone真机与自然十二场性能仍待验证。

## 价格

仅降低武器的品质倍率：精良1.75→1.5、史诗3→2.4、传说5→3.75。向上取整，实际折扣因基础价格取整略有差异。普通武器、支持件和功能件价格保留。商店、直接装入、购买并合成、图鉴与出售回收共用价格函数。

示例：传说磁轨炮240→180，精良霰弹炮63→54，史诗导弹架144→116。出售仍为当前品质价格的50%，向下取整；免费二合一仍保留。

## 四个独立主动技能

| 机体 | 技能 | 规则 | 冷却 |
|---|---|---|---:|
| 拾荒者 | 磁力回收 | 修复6生命，不超过上限；3秒内拾取半径至少320，只收集实际已有掉落 | 18秒 |
| 堡垒 | 铁壁震波 | 半径180、36基础震荡伤害，共享血条目标只处理一次；4秒受到伤害×0.5，可与护甲/应急电容叠加 | 22秒 |
| 游隼 | 疾风掠影 | 冲刺冷却归零、0.45秒无敌、3秒移速×1.35；同帧使用技能和冲刺会先重置再冲刺 | 16秒 |
| 蜂巢 | 援护蜂群 | 3架临时援护机，6秒内每0.6秒齐射一次，共10轮；每机6基础召唤伤害，受自身15%特性加成及敌方护甲影响，射程450，优先集火目标 | 24秒 |

援护机不要求无人机巢，不占装备槽、不改变已有武器实例，不触发武器支持件。技能独立于超载，按Q或触屏按钮释放；按住不会自动重复。选择机体与试炼场展示中英文效果；战斗按钮展示剩余生效时间或冷却，激活有轮廓、音效与对应机体效果。

状态为可选扩展字段，dev.10存档缺失时按就绪处理。新版技能期间的存档精确保留持续时间、冷却、蜂群下一轮时刻与按键释放状态；非法计时退回战前装配。暂停与后台不推进技能时间。
