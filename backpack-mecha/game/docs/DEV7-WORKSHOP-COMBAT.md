# dev.7：装配、追击、图鉴与首领试炼

2026-10-29；构建 `0.2.0-dev.7`，规则 `0.1.2`。本地源码与 `dist/` 已更新，本批未推送或部署 GitHub Pages。

## 对应八项需求

1. 装配页采用视口内布局，背包与出击按钮保持可见；商店、模块、路线/事件通过标签切换。长详情与战报移到弹窗。背包画布保持正方形，绘制尺寸与点击落点一致；横屏使用分栏。
2. 近战敌人有通路时直接追击，无通路时绕障、跳过多余路径点。疾跑钉虫取消导致绕圈的转向限制；追击随主角位置刷新。远程单位会接近射程、保持距离并检查视线，维修单位保留支援分工。
3. 碎片掉落增加金色堆叠图标、金额、光柱和光环，尺寸不随手机缩放到不可辨认；拾取有吸入轨迹、精确到一位小数的浮字、HUD 高亮与清晰音效。掉落与到账金额沿用原经济数值。
4. 首页自由解锁开关开放四机体与三章远征难度 0–4；开关持久保存，关闭后恢复原已获得的解锁与难度。短流程的内容档位限制仍保留。
5. 首页完整图鉴可查看 36 模块、12 小怪、36 精英变体、6 首领。精英为 12 种敌人 × 疾速/铁甲/脉冲三类词缀，复用基础模型。可按名称/编号搜索，查看形状、效果、技能及应对方法。
6. 后期新增盾卫三发扇形齐射、货箱预警迫击炮、维修浮球落单防卫弹；拖缆蜘蛛强化为双减速弹，磁暴投射器修正反向弹道并改为朝主角的五发扇形弹幕。所有新增攻击有预警。原版已有针刺哨兵、拖缆蜘蛛、磁暴投射器等远程敌人。
7. 沿用现有 2.5D 图集，进一步拆分主角肩部、腰部与行走反馈；普通敌人拆分腿组/车体、履带悬挂、浮球推进器及射击蓄能。射击后坐力绑定具体敌人，不再让同种敌人同时播放。没有引入新的 3D 网格、骨骼模型或新增大图集。
8. 首页首领试炼场可选四机体、六首领、五难度、三装备等级、四档基础电力、最多 12 件不同模块，提供六套预设。完整 25 格背包自动排布并校验连接、电力与三武器上限。可直接从图鉴挑战，结算可再战或改装；保存始终写入原远征，试炼不产生永久进度。
