# dev.8 · 装备稀有度与合成

2026-10-29。应用版本 `0.2.0-dev.8`，规则版本 `0.2.0`。源码和静态 `dist/` 已更新，本次未推送或部署 GitHub Pages。

## 玩家规则

参考 [Brotato 武器的四阶与二合一机制](https://brotato.wiki.spellsandguns.com/Weapons)及[商店随波次提高高阶供货概率](https://brotato.wiki.spellsandguns.com/Shop)。概率与数值重新适配本作十二场远征，没有照搬其完整经济系统。

- 全部 36 件模块具有普通（白）→精良（蓝）→史诗（紫）→传说（红）四档，使用颜色、名称和 I–IV 标记。
- 武器基础伤害倍率为 1 / 1.35 / 1.8 / 2.4，价格倍率为 1 / 1.75 / 3 / 5，价格向上取整。支持件与功能件按各自机制递增；追加攻击间隔随品质缩短。
- 两件同名同阶装备免费合成一件下一档，传说封顶。旧的付费直接升级入口替换为合成。形状、耗电不变；出售按当前档价格的 50% 向下取整。
- 优先保留已装备实例、位置和合法连接。备件材料优先消耗；两把已装备武器合成后若支持件断连，预览提示并要求重新整理后出击。
- 商店匹配商品支持“购买并合成”：仅支付商品价，备件满也能购买合成；确认前展示两件材料、最终品质和属性变化。失败不扣钱、不丢装备、不推进随机流。
- 锁定商品保留品质。商店保留各槽位原有型号与兼容支持规则，并有 30% 的型号选择分支优先选择已持有且未达传说的可用型号，帮助收集材料；品质仍独立抽取。
- “旧式工作台”保留一次免费的普通→精良升级。普通战利品和事件选择继续发放普通档，界面明确标记；保险熔断器合成或重购不重置单局使用次数。

每个新商品的概率：

| 场次 | 普通 | 精良 | 史诗 | 传说 |
|---|---:|---:|---:|---:|
| 2 | 92% | 8% | 0 | 0 |
| 5 | 84% | 14% | 2% | 0 |
| 9 | 69.9% | 22% | 7.6% | 0.5% |
| 12 | 58.2% | 28% | 11.8% | 2% |

商店“稀有度”按钮展示当前概率。合成不受旧章节等级上限限制；首领试炼可以直接使用任意一档装备。图鉴逐档展示价格与实际效果，购买详情、装配说明、战斗武器栏和暂停装配同步显示当前档。

## 工程与兼容

`src/rarity.ts` 集中维护四档伤害、价格、24 件非武器的传说数值及冲刺/回复/诱饵等附加效果。`src/equipment-ui.ts` 为 36 件装备生成当前档的中英文效果，避免显示原始 I–III 参数串。

原内容目录的 `ModuleDef.rarity`（C/U/R）仅保留为型号供货分组；玩家装备品质取自实例 `Item.tier` 和新 `Offer.tier`。原始 `assets/content.json` 保留设计基值，运行数值以 `rarity.ts` 为准。诱饵生命统一为原描述对应的 20/27/36 和新增 48，持续时间为 3/4/5/6 秒，修正旧实现误把持续秒数当生命的行为。

沿用 v1 数据库和存档版本。旧装备 I–III 保留，旧商品缺少 `tier` 时按普通处理；校验接纳 IV 阶背包、商店和战报。旧 `maxTier` 字段继续可读，但不再限制合成。旧自然成长探针报告属于旧经济规则，本批未宣称复测全远征平衡；探针购买搜索已改为读取商品当前档价格和品质，免费合成只提交装配依然合法的方案。
