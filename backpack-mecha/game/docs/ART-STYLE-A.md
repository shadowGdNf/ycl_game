# A 方案素材改造 · v0.2.0-dev.2

用户选择 A「风格化金属」后，本次将机体、模块、敌人与地面统一到厚装甲、宽倒角、缎面金属和柔和反光的视觉方向，并接入现有 Canvas 分层渲染。

## 已交付

| 图集 | 运行时采样区域 |
|---|---:|
| 四机体的四方向躯干、腿、背包 | 24 |
| 武器、支持、功能模块 | 36 |
| 12 敌人、6 Boss、2 个双子单机 | 20 |
| 独立母舰左右侧舱 | 2 |
| 三章地面与维护板 | 4 |
| 合计 | 86 |

敌人图集补做留白重排，避免钻头、吊臂与下一行素材互相串入。母舰侧舱从整船裁片改为完整独立透明素材。原版图集保存在 assets/source/pre-style-a/；批准的参考图为 assets/source/art-direction-a.png，均不进入网页包。

图集坐标检查现在按布局元数据读取分区，检查每个单元边缘、全部内容 ID、透明背景与文件 SHA-256；发布包也核对相同哈希，防止混入旧图。完整生成提示和来源位于 [ASSET-PROMPTS-A.json](ASSET-PROMPTS-A.json)，使用内置 image_gen。

渲染器增加柔和接地阴影和高质量缩放，保留现有四方向躯干、分层步态、独立武器朝向与危险提示。数值、碰撞范围、存档格式与战斗规则没有因本次美术改造而改变。

## 范围说明

这是基于已选方向的栅格素材改造与接入。表面光照保存在图片内，继续使用分层程序动作；没有新增可旋转 3D 模型、逐敌人动画帧或实时材质灯光。移动端验证使用浏览器视口，真机帧率与发热仍需设备实测。
