# dev.15 · 装配与战斗动态反馈

版本 `0.2.0-dev.15`，规则版本保留 `0.2.6`。这是表现层更新，沿用现有图集与存档；伤害、碰撞范围、攻击周期、随机序列与装配合法性均未修改。本地构建已更新，尚未推送或部署。

## 交互与动作

- 装配：选中浮起、指针跟随拖动图标、原位透明残影、动态虚线落点、旋转过渡、互换滑入、落位回弹和短暂扩散圈；卸下 / 出售后淡出，失败操作短促摇动并标红。
- 连接：只为 `activeSupports` 返回的有效连接绘制线路，端点跟随模块移动；光点从支持件流向武器。选中时加粗，预览连接使用虚线，减少动态时保留静态箭头。
- 武器：区分快速枪械和重武器后坐、缓冲回正、枪口焰、实弹抛壳、近战预备和扫击轨迹、电 / 光束武器充能圈，以及无人机尾迹。
- 敌人：加强分层行走、蓄力压低、释放前探和远程后坐；接触攻击从已有伤害事件显示动作。受击位移由真实来向决定，加入短暂压缩和火花十字。
- 主角：加强腿部步幅、肩臂与背包惯性、呼吸、走位侧倾、落脚尘圈、开火带动躯干和定向受击；冲刺喷焰有持续变化。
- 界面：商店卡片悬停抬起、按钮按下、面板短距淡入和出击按钮柔和发光。

## 状态和开销

`WorkshopRenderer` 缓存模块图标，装配台最多 30 次 / 秒刷新，不再逐帧创建图标画布。切后台和打开弹窗时停止装配动画时钟。减少动态时停止持续刷新，仅在操作 / 必要错误反馈时绘制。

战斗动画仍读取固定逻辑时间；暂停不会推进动作。减少动态设置抑制新增的位移、摆动、镜头震动、粒子与连接流动。无人机位置仍跟随其实际轨道。攻击危险边界继续使用原始规则几何，并在友方特效上方绘制。

## 验证

- `npm test`：189 项通过，包括装配动画期间不修改装备 / 随机状态、有效连接与撤销、动作恢复、方向和暂停 / 恢复读取。
- TypeScript 构建和静态包检查通过。
- `scripts/dev15-browser.mjs`：独立 Chrome 合成存档，检查连接连续动画、落位、撤销、走位 / 冲刺、暂停像素稳定、减少动态和设置即时切换、390×844 布局。
- 全部 18 种武器与 16 种普通敌人绘制检查：5,250 个模拟帧绘制，每帧比较完整战斗状态，未发现渲染器修改规则状态或浏览器异常。结果在 `qa/dev15-browser.json`。
- 复用 dev.13 浏览器交互场景，覆盖满备件互换、背包互换、拖动、卸下、撤销、自动旋转、触屏拖动、320×740 / 390×844 / 844×390 布局及进入战斗；独立记录为 `qa/dev15-interactions-browser.json`。

重跑：先 `npm run build && npm run dev`，在另一个终端配置本机 `PLAYWRIGHT_MODULE` / `CHROME_PATH` 后执行 `node scripts/dev15-browser.mjs`。测试使用全新浏览器上下文，不访问玩家存档。

浏览器验证使用桌面 Chrome；手机视口不能替代 Android / iPhone 真机验证。同步渲染采样耗时也不代表实际设备帧率。动作仍由现有分层图集与程序插值产生，未新增逐帧素材或真实 3D 骨骼。
