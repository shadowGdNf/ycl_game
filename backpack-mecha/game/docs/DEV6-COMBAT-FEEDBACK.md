# dev.6 首批：战斗反馈与动作修复

更新：2026-10-29。构建 `0.2.0-dev.6`，规则 `0.1.1`。本批对应用户提出的四项问题，已进入正式源码及 `dist/`，尚未部署线上。原 dev.6 的完整流程、事件、设备与真人试玩验收继续跟踪。

## 本次改动

| 问题 | 已实施的行为 |
|---|---|
| 起重机没有明显攻击动作、摆锤不扣血 | 补充关节机械臂、抬臂、吸附流、摆锤运动和砸地冲击；机械臂端点跟随真实攻击角度。活动区域逐帧检查接触，只有成功伤害后才开始伤害间隔。 |
| 击中与受击反馈弱 | 敌人受击闪色与短促后仰、方向火花、普通/暴击数字、击毁碎片；机甲区分护盾与机体受伤，增加破盾、方向提示和短促轻震。受击事件坐标修正到机甲自身。 |
| 武器与敌人特效不足 | 十二种武器分别使用枪口、弹道、水滴、电链、火舌、燃油、穿甲轨迹、锤弧、锯齿、火箭尾焰、无人机弹道与冰晶；补充敌方弹道、落地冲击和能量区域。电链击杀后仍保留正确终点。 |
| 动作僵硬 | 步态跟随实际移动距离；起步/停步平滑，转向短过渡，武器快速后坐后缓回，敌人蓄力与释放平滑衔接。无人机轨道与实际发射位置一致。 |

修复音效事件名称映射：玩家受伤、护盾、破盾、暴击、敌方开火和砸地不再落入通用点击音。对高频命中做节流，避免声音堆叠。现有“减少动态”保留，降低粒子与闪光、关闭震屏及受击闪色，攻击危险区域继续准确显示。友方特效在危险预警下层，最多保留 240 个短时视觉事件；闪色蒙版缓存最多 40 张。

## 摆锤漏伤的原因与对照

原实现每 0.5 秒检查一次摆锤区域；即使玩家不在区域内，也重置伤害间隔。窄扇形在两次检查间扫过玩家时，接触会被完全漏掉。修复保留原伤害、攻击持续时间、内圈安全区、无敌与冲刺保护，改为每个模拟帧检查接触，以成功伤害控制后续间隔。

固定场景：第一章起重机，摆锤轮次，机甲 `(1000, 300)`，初始 HP 100、护盾 5，静止。1.5 秒时原版承伤 0、HP 100、护盾 5；当前版承伤 18、HP 87、护盾 0。自动用例还验证扫击全程、内外范围、进入活动区域、伤害间隔与免疫恢复。

对照画面：[修复前](../qa/dev6-crane-before.png)、[修复后](../qa/dev6-crane-hit.png)。它们来自明确设置的开发场景，不是自然流程通关。另有回归确认初始铆钉枪能够削减起重机生命并产生正确方向的命中事件。

## 验证结果

- 类型检查、构建、包体检查通过；完整自动测试 **104 项通过**，其中本批新增 10 项，记录在 `qa/dev6-feedback-tests.txt`。
- 六路线 × 十种子的自然规则回归 **60 局完成**，**720 次**存档恢复对照通过；使用实际购买、装配、奖励和战斗 API，没有补装备、补血或强制胜利。与保留的 legacy 基线相比，60 组结局、战斗时长与最终装备相同，56 局承伤发生变化；规则修复让原来漏判的区域伤害实际生效，不能据通关结果宣称规则完全不变。结果及压缩原始记录为 `qa/dev6-feedback-natural.json` 和同名 `-runs.json.gz`。这是机器策略回归，不是真人胜率。
- 独立 Chrome 正常首场：首次引导实际使用种子 `FIRST-LIGHT`，完成 40 秒战斗，进入第 2 场休整；铆钉枪输出 342、承伤 14、击杀 24。通过键盘移动、冲刺、暂停、保存返回、刷新续局，再完成首场并导出战报。证据为 `qa/dev6-feedback-chrome-first-light.json`。它不等于十二场完整远征验收。
- 浏览器画面检查覆盖摆锤前后对照、起重机吸附、元素/火焰/近战与无人机反馈、减少动态及色彩辅助。页面未记录脚本错误。音效路由通过自动测试，Chrome 显示音频播放；未把机器操作当作真人听感评价。
- 密集战斗采用明确的 40 敌人、10000 HP 渲染场景，预热 1 秒后记录约 10 秒原始帧间隔及渲染耗时。最终 712×774 窗口保留 600 帧，帧间隔 p95 为 17.5ms、渲染 p95 为 1.7ms，结束仍在战斗且有 37 个敌人。结果见 `qa/dev6-feedback-dense-performance.json`；1280×720 窗口的前一轮记录单列为 `-wide.json`。这些只代表本机窗口；首个普通生命场景在 3.53 秒死亡，静止画面混入采样，已标为无效性能证据并保留 `-attempt1.json`。
- 正式网页目录为 **9,702,482 字节（9.25 MiB）**；未新增图集，86 个采样区域保持不变。开发场景和采样工具不进入网页包。

汇总、原始记录校验和文件指纹见 `qa/dev6-feedback-check.json`；可用 `node scripts/dev6-feedback-evidence.mjs` 复核已保存证据。该命令不重新运行浏览器或游戏。

## 兼容与范围

未修改武器伤害、Boss 生命、商店价格或地图内容。区域接触判定修复改变了实际规则，因此递增为 `0.1.1`。旧格式存档继续恢复，随后采用修正判定；旧事件缺失新视觉字段时有回退显示。视觉随机纹理只由事件 ID 和时间推导，不消耗战斗随机流，也不写回战斗状态。

动作仍基于现有 PNG 图集与部件变换，没有替换为逐帧手绘或实时 3D 骨骼模型。独立 Chrome 完整十二场、Safari、Android/iPhone 真机持续性能和真人手感评估仍待原计划验收。

## 本地体验与交付

```sh
npm run build
node scripts/serve-feedback.mjs
```

打开 `http://localhost:4198/game/` 体验正式流程；`http://localhost:4198/` 是不写存档的开发验收场景，可选武器、起重机和密集战斗。声音需勾选并由用户操作解锁。`?baseline` 仅在本机保留修复前快照时可用，不是正式网页功能。

网页包、源码包和 SHA-256 清单位于相邻 `releases/`，文件名含 `v0.2.0-dev.6`。开发包交付不代表线上已更新，也不代表原 dev.6 四批验收全部完成。
