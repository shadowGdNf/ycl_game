## 本地启动

需要 Node.js 22.18+（本次使用 24.21.0）。运行时无框架、CDN 或服务器接口依赖；构建只依赖 TypeScript 5.9。

```sh
cd backpack-mecha/game
npm ci
npm run check
npm test
npm run build
npm run dev
```

打开终端显示的 `http://localhost:4174`。开发服务器只服务 `dist/`；修改源码后重新执行 `npm run build` 并刷新。不要直接双击 HTML，ES 模块和 IndexedDB 需要 HTTP 来源。

在局域网手机上测试时，执行 `HOST=0.0.0.0 npm run dev`，使用电脑的局域网地址访问。系统防火墙可能需要允许连接。`PORT=4175 npm run dev` 可改端口。停止服务按 Ctrl+C。

静态包解压后的目录可交给任何静态 HTTP 服务器。网页资源全部使用相对路径，可以部署在子目录；无上传、账号、广告和支付逻辑。

## 操作

| 操作 | 键鼠 | 手机触屏 |
|---|---|---|
| 移动 | WASD / 方向键 | 左侧拖动浮动摇杆 |
| 冲刺 | 空格 | 右侧箭头按钮 |
| 超载 | E | 右侧闪电按钮 |
| 指定目标 | 点击 / 右键目标附近 | 右侧长按 |
| 暂停 | P / Esc | 右上暂停 |
| 背包装配 | 拖动，或选中后点击空格 | 选中后点空格，也支持拖动 |
| 旋转 | R / 旋转按钮 | 旋转按钮 |

武器最多三件。支持件必须与兼容武器边缘相邻；每把武器最多连接两件支持。青色连线代表生效；选中支持可查看当前收益和未连接原因。备件架最多三件，可直接拖入背包，或选中后点击空格。自动整理整理已装备模块，备件需主动装入。战斗中不能换装。

商店点击模块卡片可预览形状、价格、装入后的电力与占格，以及可连接的武器。选择直接装入时，点击背包中的标记完成购买；也可先买到备件架。背包标记表示模块左上角：青色「＋」可生效，橙色「○」表示支持件仍需连接。旋转会更新标记。失败时不扣款。

装配页将商店、模块详情和路线/事件分为三个标签，出击按钮固定在底部。常用手机尺寸下无需滚动整页；较长的事件和详情可在面板或弹窗内查看。右上「⋯」提供教程、战报和导出。

首页「自由解锁」打开后可选全部四机体和三章远征的 0–4 难度；关闭后恢复原本的解锁进度。首章训练、两章试炼仍按各自内容档位运行。「完整图鉴」直接查看 36 模块、12 小怪、36 精英变体和 6 首领，提供技能、应对方法与搜索。

「首领试炼场」可选机体、首领、难度、装备稀有度（I–IV）、基础电力及最多 12 件不同模块，也提供 6 套预设。使用完整 25 格背包自动安排并连接，最多三件武器；电力、兼容性或格数不合法时不能开始。结算可再战或修改配置。试炼不替换远征续局、不增加通关或解锁；试炼中刷新返回原远征。图鉴首领详情也有试炼入口。

设置提供音效、合成背景音乐、音量、减少动态效果、色彩辅助、左手操作和自动超载。切后台自动暂停。

## 装备稀有度与合成

36 件武器、支持件和功能件都有四档稀有度。颜色、罗马数字和名称共同区分品质，商店、背包、备件、详情、图鉴与试炼场使用同一套标记。

| 稀有度 | 颜色 | 武器基础伤害 | 购买价格 |
|---|---|---|---|
| I · 普通 | 白 | ×1 | ×1 |
| II · 精良 | 蓝 | ×1.35 | ×1.75 |
| III · 史诗 | 紫 | ×1.8 | ×3 |
| IV · 传说 | 红 | ×2.4 | ×5 |

价格向上取整；支持件和功能件按各自效果成长，详情和图鉴显示当前档实际数值。装备形状与耗电不随稀有度增加。出售回收当前档价格的 50%，向下取整。

休整时选中装备，在「模块」页点「合成升阶」：消耗两件同名、同稀有度装备，免费变为下一档，传说封顶。合成预览显示前后数值；优先保留已装备实例及位置。若消耗第二把已装备武器导致支持件断连，会显示提示，重新连接后才能出击。旧的花钱直接升级入口已替换为合成；「旧式工作台」仍可赠送一次普通→精良升级。

商店出现匹配商品时标记「可合成」，预览中可选择「购买并合成」，仅支付商品价格，备件架满时也能操作。锁定会保留商品及其稀有度。

每个新商品独立抽取稀有度：第 2 场精良概率 8%；第 5 场起出现史诗，第 9 场起出现传说；第 12 场为普通 58.2%、精良 28%、史诗 11.8%、传说 2%。点击商店「稀有度」查看当前场概率。合成不受旧章节等级上限限制。事件及普通战利品仍发放普通装备，作为合成材料。

## 三个内容档位

| 档位 | 内容 |
|---|---|
| 首章训练 | 拾荒者、10模块、第一章4场、压路王 |
| 两章试炼 | 拾荒者/堡垒、指定24模块、E01–E06、8场、压路王/熔炉蟹、一次协议、基础选路、难度0 |
| 三章远征 | 四机体、36模块、12敌人、三章12场、每章随机二选一Boss、9协议池、8事件池、难度0–4 |

四机体分别为拾荒者、堡垒、游隼、蜂巢；首局只开放拾荒者。完成第一章解锁堡垒；使用无人机完成第二章解锁蜂巢；三章通关解锁游隼及下一档难度。新解锁不影响当前局数值。

六条构筑路线：潮湿电链、燃油连爆、穿甲齐射、堡垒震荡、无人机编队、冰霜回弹。商店和事件提供随机组合，完整图鉴可直接浏览全部内容，存档仍记录见过的模块及成功连接。可输入或复制种子复现路线与随机序列；操作差异仍会改变战斗结果。

## 存档

IndexedDB 数据库 `backpack-mecha-v1`，单一续局槽。交易与阶段变化后保存，战斗每5个游戏秒保存完整快照，暂停/切后台时也保存。快照包括随机流、弹丸、区域、状态层、冷却、掉落、统计和已结算标记。

不同浏览器、端口和部署域名拥有独立存档。保存失败时页面显示提示，当前内存游戏仍可继续；隐私模式和浏览器清理可能导致数据丢失。损坏的战斗快照退回当前战前装配，版本不兼容的整局会放弃并保留可识别的永久进度。结算页可导出本局战斗/购买记录 JSON，此记录不是可导入存档。

v0.2 沿用原存档格式与数据库，兼容 v0.1 续局。dev.8 保留旧装备 I–III 阶；旧商店缺少稀有度字段时按普通处理，新增传说装备、商店供货及战斗快照可正常续存。dev.6 恢复旧局后采用 `0.1.1` 的修正区域伤害判定，不锁定旧漏洞；新事件字段可缺省。新增战报独立校验，旧存档和损坏的战报不会导致有效游戏进度被删除。休整和结算都可以导出本局战报，包含最多 400 条操作/供货记录、逐场装配与战损、可见休整时间和浏览器帧间隔统计；全部留在本地，不自动上传。撤销交易会回滚经济状态，同时保留战报中的操作历史。战报不是输入回放或可导入存档。

dev.5 战报额外保留每场最近 3,600 个前台战斗帧间隔和渲染耗时，导出最近窗口的 p50/p95、最长停顿和超过 50ms 比例。暂停、后台和刷新间隔不采样；构建、视口、画布或显示设置变化后重新开始窗口。整场分桶统计继续保留，窗口 p95 不能称为整场精确 p95。原始记录留在本地，旧续局仍兼容。
