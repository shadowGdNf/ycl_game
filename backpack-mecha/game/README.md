## 本地启动

需要 Node.js 22.18+（本次使用 24.21.0）。运行时无框架、CDN 或服务器接口依赖；构建只依赖 TypeScript 5.9。

```sh
cd backpack-mecha/game
npm ci
npm run check
npm test
npm run build
npm run dev
```

打开终端显示的 `http://localhost:4174`。开发服务器只服务 `dist/`；修改源码后重新执行 `npm run build` 并刷新。不要直接双击 HTML，ES 模块和 IndexedDB 需要 HTTP 来源。

在局域网手机上测试时，执行 `HOST=0.0.0.0 npm run dev`，使用电脑的局域网地址访问。系统防火墙可能需要允许连接。`PORT=4175 npm run dev` 可改端口。停止服务按 Ctrl+C。

静态包解压后的目录可交给任何静态 HTTP 服务器。网页资源全部使用相对路径，可以部署在子目录；无上传、账号、广告和支付逻辑。

## 操作

| 操作 | 键鼠 | 手机触屏 |
|---|---|---|
| 移动 | WASD / 方向键，或左键按住拖动，松开停止 | 左侧拖动浮动摇杆 |
| 冲刺 | 空格 | 右侧箭头按钮 |
| 超载 | E | 右侧闪电按钮 |
| 机体技能 | Q | 冲刺上方的专属技能按钮 |
| 指定目标 | 右键目标附近 | 右侧长按 |
| 暂停 | P / Esc | 右上暂停 |
| 背包装配 | 拖动，或选中后点击目标；点另一件可互换 | 点选后点目标或拖动，方向自动适配 |
| 旋转 | R / 旋转按钮 | 旋转按钮 |

武器最多三件。支持件只有与兼容武器边缘相邻并连接后才生效；每把武器最多连接两件支持。青色连线代表生效；选中支持可查看当前收益和未连接原因。备件架最多三件，可直接拖入背包、点选后点击目标，或使用「自动装入」。放置会优先使用所选朝向，放不下时尝试其他朝向；横向两格武器可直接装入竖向两格空位。选中模块后点击另一件已装备模块（任意占格），或拖到其上，可原子互换；满备件也能与背包互换。拖到备件区或点击「移入备件」可卸下。拖动保留实际抓取点，松手偏离少许时会吸附附近合法位置，落位以高亮预览为准；拖出较远不会自动放置。失败保留原状，移动、互换、卸下、旋转与直接放置购买均可撤销一步；Esc / × 取消选择。空间整理允许暂时超电力，出击仍严格校验。自动整理仅移动已装备模块，尽量建立连接；无武器、电力超限、不兼容或连接位已满也可以整理，不出售或丢弃模块，备件需主动装入。未生效支持件会在出击前列出名称、原因和调整方法，可返回调整或选择「仍然出击」。失效件仍占空间和电力，但不提供战斗增益。战斗中不能换装。

商店点击模块卡片可预览形状、价格、装入后的电力与占格，以及可连接的武器。选择直接装入时，点击背包中的标记完成购买；也可先买到备件架。背包标记表示模块左上角：青色「＋」可生效，橙色「○」表示支持件仍需连接。所有可用朝向均显示标记，R / 旋转选择优先朝向；悬停或拖动显示完整占格预览。⇄ 表示互换，↻ 表示自动转向。失败时不扣款。

装配页将商店、模块详情和路线/事件分为三个标签，出击按钮固定在底部。每次进入休整或继续休整存档，默认显示商店。本局所选路线会保留到后续可选路关卡，刷新续局也保留；Boss 战临时使用普通路线，新一局重置。本次休整没有花费任何碎片就出击时，会询问是否直接闯关；购买装备、刷新、维修或付费事件均算消费，免费装配与出售不算。消费记录可随存档恢复，下一站重新判断；首场开局与首领试炼不弹此提醒。常用手机尺寸下无需滚动整页；较长的事件和详情可在面板或弹窗内查看。右上「⋯」提供教程、战报和导出。

首页「自由解锁」打开后可选全部四机体和三章远征的 0–4 难度；关闭后恢复原本的解锁进度。首章训练、两章试炼仍按各自内容档位运行。「完整图鉴」直接查看 42 模块、16 小怪、48 精英变体和 6 首领，提供技能、应对方法与搜索。

「首领试炼场」可选机体、首领、难度、装备稀有度（I–IV）、基础电力及最多 12 件不同模块，也提供 6 套预设。使用完整 25 格背包，首次预设自动安排并连接，最多三件武器。可在大背包里拖动、点选放置、互换、旋转和选择连接，支持整理、移除与撤销；添加模块尽量保留已有位置。切换首领、难度、品质或本次会话中再战，保留手动布局，开战不重新整理；刷新页面后仍恢复默认试炼配置。电力、格数、武器数量不合法时不能开始；不兼容支持件会提示原因，可确认继续。结算可再战或修改配置。试炼不替换远征续局、不增加通关或解锁；试炼中刷新返回原远征。图鉴首领详情也有试炼入口。

设置提供音效、合成背景音乐、音量、减少动态效果、色彩辅助、左手操作和自动超载。切后台自动暂停。

## 装备稀有度与合成

42 件武器、支持件和功能件都有四档稀有度。颜色、罗马数字和名称共同区分品质，商店、背包、备件、详情、图鉴与试炼场使用同一套标记。

| 稀有度 | 颜色 | 武器基础伤害 | 武器购买价格 | 支持 / 功能价格 |
|---|---|---|---|---|
| I · 普通 | 白 | ×1 | ×1 | ×1 |
| II · 精良 | 蓝 | ×1.35 | ×1.5 | ×1.75 |
| III · 史诗 | 紫 | ×1.8 | ×2.4 | ×3 |
| IV · 传说 | 红 | ×2.4 | ×3.75 | ×5 |

价格向上取整；支持件和功能件按各自效果成长，详情和图鉴显示当前档实际数值。装备形状与耗电不随稀有度增加。出售回收当前档价格的 50%，向下取整。

休整时选中装备，在「模块」页点「合成升阶」：消耗两件同名、同稀有度装备，免费变为下一档，传说封顶。合成预览显示前后数值；优先保留已装备实例及位置。若消耗第二把已装备武器导致支持件断连，会显示提示，可重新连接，也可带着未生效配件继续出击。旧的花钱直接升级入口已替换为合成；「旧式工作台」仍可赠送一次普通→精良升级。

商店出现匹配商品时标记「可合成」，预览中可选择「购买并合成」，仅支付商品价格，备件架满时也能操作。锁定会保留商品及其稀有度。

每个新商品和新战利品独立抽取稀有度：第 2 场精良概率 12%；第 5 场史诗 6%；第 9 场传说 4%；第 12 场为普通 26%、精良 38%、史诗 26%、传说 10%。点击商店「稀有度」查看当前场概率。锁定商品保留品质；战利品品质在选项生成时确定，查看、失败领取或刷新页面不会重抽。旧存档中未记录品质的奖励仍按普通领取。

击杀掉落不再被后期增加的怪物数量摊薄。同种普通怪在第 1 / 5 / 9 / 11 场的掉落价值分别为首场的 1 / 2.2 / 3.4 / 4 倍。自然刷怪按敌人消耗的预算计价；召唤与分裂子怪仍不额外产出碎片。掉落、拾取和结算采用同一数值，通关基础奖励另计。

三章远征新增侧刃游猎者（第 2 场起）、长针狙击手（第 3 场起）、熔渣布雷车（第 5 场起）、环波哨兵（第 7 场起），分别采用侧翼短突进、远距蓄力狙击、双雷区封路和环形慢弹。原有两个教学档位的怪物池保留。

## 机体等级与专精

这是局内成长，每次新远征从 Lv.1 开始，上限 Lv.12。胜利结算获得 `30 + 本场编号×5 + min(击杀数, 60)` 经验；升到下一级需要 `35 + (当前等级−1)×15` 经验。每次升级自动增加生命上限、基础攻速和基础攻击，并获得 1 个专精点；在装配台点击等级按钮，将点数投入三项中的任意一项，额外获得该角色一次对应属性成长。不消耗碎片。

| 机体 | 每级生命 | 每级基础攻速 | 每级基础攻击 | 升级方向 |
| --- | --- | --- | --- | --- |
| 拾荒者 | +8 | +4% | +5% | 全能回收，均衡成长 |
| 堡垒 | +14 | +2% | +4% | 重装耐久 |
| 游隼 | +5 | +7% | +3% | 高攻速连射 |
| 蜂巢 | +6 | +3% | +8% | 蜂群火控，保留召唤伤害加成 |

攻速和攻击以 100% 为初始基数，成长百分比相加，再与装备增益相乘。增加生命上限时仅回复新增的生命，不会自动回满；维修、事件治疗与战斗读取新的生命上限。攻击成长同样作用于机体技能，蜂巢 Q 的攻击间隔也随基础攻速缩短。休整时可分配点数，战斗内禁止改点；刷新与续局保留成长，旧存档缺少成长字段时按 Lv.1 继续。

新增武器：转轮机枪（高速单弹）、等离子光矛（不穿墙的贯穿光束）、特斯拉脉冲（周身电伤）、冰晶霰射器（散射叠寒冷）、燃烧迫击炮（范围燃烧与油污引爆）、突击蜂群（三机召唤）。全部接入四档稀有度、商店、奖励、合成、图鉴和首领试炼；首章训练 / 两章试炼继续沿用各自精简内容池。

## 存档

IndexedDB 数据库 `backpack-mecha-v1`，单一续局槽。交易与阶段变化后保存，战斗每5个游戏秒保存完整快照，暂停/切后台时也保存。快照包括随机流、弹丸、区域、状态层、冷却、掉落、统计和已结算标记。

不同浏览器、端口和部署域名拥有独立存档。保存失败时页面显示提示，当前内存游戏仍可继续；隐私模式和浏览器清理可能导致数据丢失。损坏的战斗快照退回当前战前装配，版本不兼容的整局会放弃并保留可识别的永久进度。结算页可导出本局战斗/购买记录 JSON，此记录不是可导入存档。

v0.2 沿用原存档格式与数据库，兼容 v0.1 续局。dev.8 保留旧装备 I–III 阶；旧商店缺少稀有度字段时按普通处理，新增传说装备、商店供货及战斗快照可正常续存。dev.6 恢复旧局后采用 `0.1.1` 的修正区域伤害判定，不锁定旧漏洞；新事件字段可缺省。新增战报独立校验，旧存档和损坏的战报不会导致有效游戏进度被删除。休整和结算都可以导出本局战报，包含最多 400 条操作/供货记录、逐场装配与战损、可见休整时间和浏览器帧间隔统计；全部留在本地，不自动上传。撤销交易会回滚经济状态，同时保留战报中的操作历史。战报不是输入回放或可导入存档。

dev.5 战报额外保留每场最近 3,600 个前台战斗帧间隔和渲染耗时，导出最近窗口的 p50/p95、最长停顿和超过 50ms 比例。暂停、后台和刷新间隔不采样；构建、视口、画布或显示设置变化后重新开始窗口。整场分桶统计继续保留，窗口 p95 不能称为整场精确 p95。原始记录留在本地，旧续局仍兼容。
